# CODE Eternal Scoop Bucket

Official Windows Scoop bucket for **PADAM Studio** (`v0.8.0`, PADAM License 1.0).

## Install

```powershell
scoop bucket add codeeternal https://github.com/MaksimGalatin/scoop-bucket
scoop install codeeternal/padam-studio
```
